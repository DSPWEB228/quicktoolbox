About this tool

Compress PDF makes a PDF smaller by re-rendering each page as an image at a lower quality. It works best on scanned or image-heavy documents, and it runs entirely in your browser.

How to use it

  1. Choose a PDF file, or drag it onto the upload area.
  2. Set the compression quality. Lower values give smaller files.
  3. Click Compress PDF and wait while each page is processed.
  4. Check the original and compressed sizes, then download the new PDF.

Tips and limits

Because pages are turned into images, text in the compressed PDF is no longer selectable or searchable. Keep your original file if you need to copy text from it. Very long PDFs can take a while on slower devices.

Frequently asked questions

Why is the text not selectable afterwards?

Each page is saved as an image, so the text layer is not kept.

Is my PDF uploaded?

No. The file is processed on your device.

Why did my file barely shrink?

PDFs that are mostly text and vector graphics are already small; this method helps most with scans and photos.
